# Code of conduct

Be kind and constructive. This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: welcome people of every background and level of experience, criticise ideas rather than
people, and don't harass anyone in issues, pull requests or anywhere else connected with the project.

Report unacceptable behaviour privately to the maintainer through the contact on their GitHub profile.
Reports are handled confidentially, and the maintainer may remove comments or block participants who
break these rules.
